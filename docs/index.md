# GitHub-квиз

Консольная викторина по Git и GitHub на C#.

## Правила

- Вопросов семь, у каждого три варианта ответа.
- Отвечай номером варианта и нажимай Enter.
- В конце программа покажет итог в процентах.

## Пример вопроса

> Что делает git fetch?
>
> 1. Забирает новые коммиты с сервера, но не трогает твои файлы и ветки
> 2. Забирает коммиты и сразу сливает их с твоей веткой
> 3. Отправляет твои коммиты на GitHub

## Как запустить

```
git clone https://github.com/GlebKievsky/github-quiz-demo.git
cd github-quiz-demo
dotnet run
```
